### Markup Languages - Portability
- Language to describe the purpose of language, an annotation layer
- This is how we embed and pull metadata
- *Archivists often use XML, eXtensible Markup Language, to manage metadata*
	- It's like HTML, but instead of having a universal meaning for tags, it's meaning is established per document

### Robots.txt

- A document that tells crawlers to ignore sites
- This is how publishers exclude content from the Wayback Machine
- Recently, The New York Times and other news sites have forbid Wayback Crawlers
